02模型 × 数据集

同一骨干在两个数据集上的测试准确率；色阶按当前视图的最低–最高值拉伸

D1 是 271 张原图（5184×3456 下采样到 224），D2 是作者提供的 3017 张增强图（128 上采样到 224）。两个数据集的难度不可直接比较。

03优化器消融

同一模型换优化器，测试准确率变化

Adam / SGD / RMSprop 各跑同一套冻结策略与学习率（1e-3）。横条 = 三种优化器之间测试准确率的最大差值（百分点），右侧同时给出区间与最差的那个优化器。条为 0 表示该模型对优化器完全不敏感。

04效率

训练时长（对数轴）× 测试准确率；点越大可训练参数越多

横轴是单个 run 的训练时长（30 秒到 15 分钟，对数轴）。右上角是"又准又快"，右下角是"慢且不划算"。冻结卷积后只训练分类头，可训练参数反映的是特征维度而不是骨干体量。
